# Flowchart tapşırıqları

Hər tapşırığın blok-sxemi "Cavab" linkindədir.

1. İki ədəd daxil edin. Onların cəmini hesablayıb ekranda göstərin.
   **[Cavab](1.png)**

2. Düzbucaqlının uzunluğunu və enini daxil edin. Sahəsini və perimetrini hesablayıb ekranda göstərin.
   **[Cavab](2.png)**

3. Müsbət üçrəqəmli ədəd daxil edin. Tam bölmə və qalıqdan istifadə edərək rəqəmlərinin cəmini hesablayıb ekranda göstərin.
   Nümunə: 345 → 3 + 4 + 5 = 12.
   **[Cavab](3.png)**

4. Verilmiş n tam ədədinin həm 3-ə, həm də 7-yə qalıqsız bölünüb-bölünmədiyini müəyyən edib nəticəni ekranda göstərin.
   **[Cavab](4.png)**

5. n və m tam ədədləri verilir. Hər iki ədəd cütdürsə, onların cəmini hesablayıb ekranda göstərin. Əks halda, "Hər iki ədəd cüt deyil" yazısını göstərin.
   **[Cavab](5.png)**

6. Verilmiş n və m tam ədədləri (n < m) arasındakı tək ədədlərin sayını tapıb ekranda göstərin. n və m sərhədlərini hesaba daxil etməyin.
   **[Cavab](6.png)**

7. Verilmiş n tam ədədinin həm 2-yə, həm də 5-ə qalıqsız bölünüb-bölünmədiyini müəyyən edib nəticəni ekranda göstərin.
   **[Cavab](7.png)**

8. n və m tam ədədləri verilir. Hər iki ədəd təkdirsə, onların hasilini hesablayıb ekranda göstərin. Əks halda, "Hər iki ədəd tək deyil" yazısını göstərin.
   **[Cavab](8.png)**

9. Verilmiş n və m tam ədədləri (n < m) arasındakı cüt ədədlərin cəmini hesablayıb ekranda göstərin. n və m sərhədlərini hesaba daxil etməyin.
   **[Cavab](9.png)**
